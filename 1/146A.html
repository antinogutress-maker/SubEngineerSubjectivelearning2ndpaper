Checks & Adjustments

SIMULATING

1. Angular Check

Verify the geometric closure of the observed polygon angles before checking lengths.

Internal Angles Sum (Σθ)
Σθ = (2n - 4) × 90°

2. Closing Error (e)

If the traverse fails to close, the gap is the Closing Error, caused by errors in Latitude (ΣL) and Departure (ΣD).

Error Magnitude
e = √[ (ΣL)² + (ΣD)² ]

3. Bowditch Rule

Correction is proportional to the length of the side. Used when linear & angular precision are consistent (e.g., Compass traverse).

Correction in Latitude (c_l)
c_l = -ΣL × ( l / Σl )

4. Transit Rule

Correction is proportional to the Latitude/Departure. Used when angular measurements are more precise than linear (e.g., Theodolite traverse).

Correction in Latitude (c_l)
c_l = -ΣL × ( |L| / Σ|L| )

5. Graphical Method

Visual parallel adjustment of the traverse skeleton. The total error vector is distributed across the perimeter line linearly. Used for rough Plane Table surveys.

Technique
Parallel Vector Distribution
